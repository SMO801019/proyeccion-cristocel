# 🔥 PROMPT MAESTRO PARA HERCULES AI (FRONT + BACKEND COMPLETO)

> **Úsalo tal cual** para generar una plataforma SaaS de proyección + CRM para iglesias, alineada con la identidad visual y narrativa de **Cristo Cel**.

## 🧠 PROMPT

Quiero que construyas una plataforma web SaaS completa, moderna, escalable y modular para iglesias cristianas, inspirada en la funcionalidad de Wiswords para proyección y administración de contenido, pero combinada con el lenguaje visual, estructura comercial y esencia de marca de Cristo Cel, incluyendo su enfoque de “Conexión con Propósito”, navegación clara, experiencia moderna y ecosistema de servicios.

### 🎯 Objetivo general

Desarrollar una plataforma integral para iglesias y ministerios que combine en un solo sistema:

- Proyección en vivo de Biblia, canciones, videos, imágenes, anuncios y orden del servicio.
- CRM ministerial para miembros, líderes, visitantes, células, seguimiento pastoral y voluntariado.
- Panel administrativo multi-iglesia / multi-sede tipo SaaS.
- Portal de conexión con devocionales, recursos, consejería, videollamadas y acompañamiento espiritual.
- Sistema comercial y de crecimiento para escalar el producto como servicio a iglesias, redes de iglesias y ministerios.

---

### 🖥️ Enfoque visual y de marca

Quiero una interfaz que combine:

- la limpieza de un SaaS moderno,
- la calidez espiritual y humana de una plataforma cristiana,
- con una estética inspirada en Cristo Cel: moderna, amigable, confiable, limpia, visual y orientada a conversión.

**Identidad visual deseada**
- Estilo minimalista, profesional y emocional.
- Sensación de tecnología + propósito.
- Diseño elegante, con tarjetas bien acomodadas, geometría limpia y espaciado generoso.
- Experiencia responsive mobile, tablet y desktop.
- UI pensada para usuarios no técnicos.

**Colores base**
- Azul principal: `#00599c`
- Azul suave / secundario: `#82b8c9`
- Blanco limpio
- Grises suaves para fondos y bordes
- Posibles acentos sutiles en dorado tenue o verde esperanza para estados positivos

**Tipografía**
- Inter o Poppins
- Jerarquía visual clara
- Títulos fuertes, textos legibles
- Estilo premium y sencillo

**Tono de experiencia**
- Espiritual pero no anticuada
- Moderna pero cercana
- Tecnológica pero sencilla
- Comercializable para iglesias grandes y pequeñas

**Nombre conceptual temporal**
- “La Red | Plataforma de Proyección, Gestión y Conexión”
- o “La Red powered by Cristo Cel”
